# 🛠 Workbench

一个本地工作台：左边文件树，中间 Markdown/文本 **阅读 · 渲染 · 编辑**（实时预览），右边一个**工具箱**面板。纯 Python 标准库后端 + 原生前端，零第三方依赖，离线可用。

## 启动

```bash
# 默认以 J:\ 为根目录, 端口 8123
python server.py

# 指定根目录和端口
python server.py D:\notes --port 8200
```

Windows 可直接双击 `start.bat`（默认根目录 `J:\`），或把任意文件夹**拖到 `start.bat` 上**以该文件夹为根启动。

启动后浏览器打开 `http://127.0.0.1:8123/`。

## 功能（v0.2）

VS Code 风格的轻量三栏布局：**活动栏（图标）→ 侧边栏（随图标切换）→ 中间编辑区**。

最左活动栏三个图标切换侧边栏视图：

- **🗂 资源管理器**：文件树，浏览根目录、点击展开文件夹。
- **⎇ 源代码管理（Git）**：仿 Cursor/VS Code，侧栏分两块——
  - **更改**：提交信息框 + `提交`，分 **暂存的更改 / 更改** 可折叠分组（带 `M/A/D/U` 状态色）；文件行 hover 浮出 `打开 / 丢弃 / 暂存±` 动作，单击看 diff，组级一键暂存/取消全部。`Ctrl+Enter` 快捷提交，可 `推送 / 初始化`。
  - **图形**：侧栏内的紧凑提交图——SVG 多 lane 节点+连线（HEAD 空心环）+ 单行提交消息 + 分支/标签胶囊；头部分支选择器可切「所有分支 / 某分支」；鼠标悬浮某条提交弹出详情卡（作者/时间/改动统计/分支/hash）。
  - 侧栏宽度可**拖动调节**（拖右缘，记忆到本地）。
- **🧰 工具箱**（纯前端）：JSON 格式化/压缩/转义、Base64、URL 编解码、时间戳 ⇄ 日期、Hash（SHA-1/256/384/512）、字数统计（含中文）。

中间编辑区：

- **Markdown**：左源码右渲染、实时预览；顶栏按钮切换 `分屏 / 源码 / 预览`，代码块语法高亮。
- **文本编辑**：任意文本文件可编辑，`Ctrl+S` 保存（保存后自动刷新 Git 状态）；Tab 键插入两空格。
- **图片**：直接预览；二进制文件提示无法编辑。

## 安全

- 所有文件读写限制在根目录内，`..` 路径穿越会被拒绝。
- 默认只监听 `127.0.0.1`，不对外网开放。

## 目录结构

```
workbench/
├─ server.py          # 后端 (标准库 http.server)
├─ start.bat          # Windows 一键启动
└─ static/
   ├─ index.html
   ├─ style.css
   ├─ app.js          # 视图切换 / 文件树 / 编辑 / 预览 / diff
   ├─ git.js          # 源代码管理视图
   ├─ tools.js        # 工具箱
   └─ vendor/         # marked + highlight.js (本地, 离线)
```
